# 5.0.0 Performance Engine

This release hardens the blur work controller so the same public neumorphic API
stays responsive across low-end, mid-range, and flagship devices.

## Goals

1. Bound CPU/GPU work for first-paint and cache-miss shadows.
2. React to thermal pressure and battery saver without thrashing quality.
3. Keep cache identity exact so a degraded frame is never reused as a high-quality frame.
4. Avoid undoing memory-pressure protections on every `BlurMaker` lookup.

## Performance class

`NeuPerformanceConfig.performanceClass`:

| Class | Intent |
| --- | --- |
| `QUALITY` | Higher work budget; only thermal/power may reduce quality |
| `BALANCED` | Default adaptive budget |
| `BATTERY` | Lower budget + higher minimum sampling |
| `AUTO` | `BALANCED` normally, `BATTERY` under power-save or severe thermal pressure |

## Effective work budget pipeline

```
app blurWorkBudget
  → performance-class multiplier
  → thermal multiplier (with hysteresis)
  → power-save multiplier
  → NeuRenderPolicy.effectiveBlurSampling(...)
```

Sampling is still discrete (`1..4` unless the app forces a higher floor). The
selector never reduces an explicit caller sampling floor.

## Thermal hysteresis

Thermal escalations apply immediately. Recoveries wait for
`NeuPerformanceConfig.qualityHysteresisMs` (default 400ms) so quality does not
oscillate near tier boundaries.

## Battery awareness

When `batteryAwareRendering` is enabled and the device is in power-save mode:

- work budget is reduced
- minimum sampling floor rises to 3

## Cache identity

Shadow cache keys include:

- geometry and exact float bits for elevation/stroke
- blur downsampling / adaptive / work budget
- thermal tier and power tier
- resolved performance class

## Memory pressure

`NeuBlurMakerHolder.get()` no longer restores the configured cache budget on
every call. Temporary reductions from `ComponentCallbacks2` remain in effect
until the app sets `shadowCacheBudgetKB` again or pressure fully clears through
existing restore helpers.

## Device-class expectations

| Device class | Expected behavior |
| --- | --- |
| Low-end / Go | Higher sampling, more cache reuse, BATTERY under saver |
| Mid-range | BALANCED adaptive sampling, stable lists after warm cache |
| Flagship 120Hz | QUALITY or AUTO; quantization still protects animation cache |
| Hot device | thermal tiers reduce work immediately, recover with hysteresis |
| Power save | BATTERY-like bounds regardless of class (when battery-aware) |

## Additional engine work (same release track)

- **Foreground mask+tint**: pressed shadows cache white geometry masks and apply light/dark colors at draw time.
- **Soft alpha after StackBlur**: blurred intensity drives alpha so masks do not keep hard silhouettes.
- **Rounded blur radius after downsample**: avoids systematic under-blur when sampling > 1.
- **Hardware bitmap promotion** (API 26+): completed shadows upload once for cheaper repeated draws.
- **Two-level cache**: hot access-ordered map protects frequently reused list-item shadows from LRU churn.
